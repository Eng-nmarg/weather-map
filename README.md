# weather-map
an elegant, responsive Single Page Application named 'WeatherMap'. The application accepts a user-specified geographic location (city, address, or point of interest), asynchronously resolves its coordinates using a geocoding mechanism, centers a map on the location, and queries weather details using the OpenWeatherMap API.
